# Memories iOS - Development Setup

This guide covers the development environment setup, build commands, and project configuration for Memories iOS.

---

## 🛠️ Prerequisites

### Required Tools
| Tool | Version | Installation | Purpose |
|------|---------|--------------|---------|
| Xcode | 16+ | App Store | iOS development, simulator |
| [XcodeGen](https://github.com/yonaskolb/XcodeGen) | Latest | `brew install xcodegen` | Generate Xcode project from spec |
| iOS Simulator | iOS 16+ | Built into Xcode | Testing |

### Recommended Setup
- **Simulators**: Create these simulators for testing:
  - iPhone 16 (for builds and tests)
  - iPhone 17 Pro Max (6.9" for App Store screenshots)
  - iPad Pro 13-inch (M5) (13" for App Store screenshots)
- **Note**: Never use your personal "iPhone 17 Pro" for development testing

## 🏗️ Project Configuration

### XcodeGen
The Xcode project is **generated from `project.yml`** using XcodeGen.

**Key rule**: `project.yml` is the **source of truth**. Never edit `MemoriesIOS.xcodeproj` directly.

#### Regenerating the Project
```bash
cd MemoriesIOS
xcodegen generate
```
- **When to run**: After adding/removing files or editing `project.yml`
- **Info.plist**: Generated by XcodeGen from the `info:` section of `project.yml` (do not edit by hand)

#### Settings in Xcode UI
- Any settings changed in Xcode's UI land in `.pbxproj` only
- **These changes are lost** on the next `xcodegen generate`
- **Solution**: Copy settings into `project.yml`

## 🚀 Build Commands

### Build for Simulator
```bash
# Basic build
xcodebuild -project MemoriesIOS/MemoriesIOS.xcodeproj -scheme MemoriesIOS \
  -destination 'platform=iOS Simulator,name=iPhone 16' build

# Clean build
xcodebuild -project MemoriesIOS/MemoriesIOS.xcodeproj -scheme MemoriesIOS \
  -destination 'platform=iOS Simulator,name=iPhone 16' clean build
```

### Run on Simulator
```bash
# Open in Xcode and run
open MemoriesIOS/MemoriesIOS.xcodeproj
# Then select the "MemoriesIOS" scheme and run

# Or via command line (requires Xcode)
xcodebuild -project MemoriesIOS/MemoriesIOS.xcodeproj -scheme MemoriesIOS \
  -destination 'platform=iOS Simulator,name=iPhone 16' build
```

### Build for Device
1. Select your development team under **Signing & Capabilities** in Xcode
2. Select your device as the build target
3. Build and run (⌘R)

**Note**: You cannot build for device via command line without proper provisioning profiles.

## 🧪 Running Tests

### Unit Tests
```bash
# Run all unit tests
xcodebuild -project MemoriesIOS/MemoriesIOS.xcodeproj -scheme MemoriesIOS \
  -destination 'platform=iOS Simulator,name=iPhone 16' test
```

### Test Organization
- Tests mirror the source structure (`Tests/App/`, `Tests/Auth/`, etc.)
- Shared test data: `Tests/Support/Fixtures.swift`
- **Important**: Unit tests should focus on **pure logic** (no network, no web view)

### Special Test Cases
- `CredentialStoreTests`: Uses its own Keychain service (never touches real account)

## 📝 Code Style & Conventions

### Language
- **All code must be in English** (see [Contributing Guidelines](CONTRIBUTING.md#language-policy))
- Comments, doc comments, and log messages: English only

### Swift Version
- **Swift 5 language mode** (compatible with iOS 16+)
- **No `@Observable`**: Use `ObservableObject` for iOS 16 compatibility

### File Organization
- **Short files**: One responsibility per file
- **Naming**: Follow Swift naming conventions (PascalCase for types, camelCase for functions/variables)

## 📱 Simulator Tips

### Managing Simulators
```bash
# List all simulators
xcrun simctl list devices

# Create a new simulator
xcrun simctl create "iPhone 16 Test" "iPhone 16" "iOS 16.5"

# Delete a simulator
xcrun simctl delete "iPhone 16 Test"
```

### Status Bar Override (for Screenshots)
```bash
# Get device UDID
xcrun simctl list devices | grep "iPhone 17 Pro Max"

# Override status bar (time, battery, etc.)
xcrun simctl status_bar <UDID> override --time 9:41 --batteryLevel 100 --batteryState charged
```

### Photos Permissions
```bash
# Grant photos access to the app
xcrun simctl privacy booted grant photos fr.midiland.memories

# Revoke photos access
xcrun simctl privacy booted revoke photos fr.midiland.memories
```

### Adding Test Media
```bash
# Add photos from a directory
xcrun simctl addmedia booted /path/to/photos

# Add a single photo
xcrun simctl addmedia booted /path/to/photo.jpg
```
